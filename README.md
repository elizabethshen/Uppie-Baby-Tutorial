## Uppie Baby Tutorial

I am going to create a project called **Uppie Baby Tutorial**, a simple tutorial, to make Data Science an easy learning process for every one.<br> 

I like to make things simple, just like math formulas, simple and adoptable. <br>
<br>
When I started to learn Data Science, I found many knowledges sharing online were very useful,
but unnecessarily complex. <br>

If we can solve them in a simple way, there is no need to make it complicated.
If we need from A to B, we go from A to B directly, no need from A - C- D - E - B <br>
<br>
This is Uppie, a real Lab ( with an AI Epee)! <br><br>
